## Selected projects

### Security & AI

**[adversarial-malware-detection](https://github.com/Raimondo-sys/adversarial-malware-detection)**
Malware detection on Windows PE files with Random Forest (EMBER features) and deep learning on raw bytes. Uncovers a dataset bias with SHAP and evaluates robustness against GAMMA adversarial attacks, showing why threshold tuning alone is not a defence.
`Python` `scikit-learn` `PyTorch` `SHAP`

**[fitterapp-secure-cloud](https://github.com/Raimondo-sys/fitterapp-secure-cloud)**
Secure-by-design Kubernetes deployment of a machine learning application: mTLS, JWT RS256, default-deny NetworkPolicies, hardened container images, encryption at rest and Falco runtime monitoring.
`Kubernetes` `Docker` `FastAPI` `PostgreSQL` `Redis`

**[aps-verifiable-credentials](https://github.com/Raimondo-sys/aps-verifiable-credentials)**
Verifiable Credentials with RSA-PSS signatures, Merkle-tree selective disclosure and revocation, followed by a security review of the protocol with working proof-of-concept attacks.
`Python` `Cryptography` `Merkle trees`

**[PW_Blockchain_G07](https://github.com/Raimondo-sys/PW_Blockchain_G07)**
Decentralized governance for logging security policies on an EVM proof-of-authority network, with self-sovereign identities, hybrid encryption and IPFS storage.
`Solidity` `Hardhat` `TypeScript` `React`

### Machine learning

**[offroad-semantic-segmentation-unet](https://github.com/Raimondo-sys/offroad-semantic-segmentation-unet)**
Semantic segmentation of off-road driving scenes with a U-Net and ResNet34 encoder: manual dataset cleaning, class-imbalance handling and progressive fine-tuning within a 5 GB GPU budget.
`PyTorch` `segmentation-models-pytorch` `Computer vision`
